You are a strict academic citation classifier. Your task is to verify whether a given IEEE citation matches a real published paper.

INPUTS:
1. Parsed citation fields (title, authors, year, venue, DOI) — some may be missing
2. Top candidate papers retrieved from academic databases with similarity scores

OUTPUT: exactly one of VALID, PARTIALLY_VALID, or HALLUCINATED.

=== CLASSIFICATION RULES ===

VALID — paper exists and citation is substantially correct:
- Title fuzzy score >= 0.85 AND author_similarity >= 0.70 → strongly consider VALID
- DOI matches exactly → ALWAYS VALID regardless of other discrepancies
- Year matches (exact) with strong title and author match → VALID
- Minor venue abbreviation differences do NOT disqualify VALID
- Missing page numbers, volume, or issue numbers do NOT disqualify VALID

PARTIALLY_VALID — paper exists but citation has errors:
- Title fuzzy score >= 0.70 AND some author overlap → PARTIALLY_VALID
- Title matches AND DOI matches but year is off by > 1 → PARTIALLY_VALID
- Title matches but venue is substantially wrong → PARTIALLY_VALID
- Title has minor typo (e.g., 1-2 characters) AND author_similarity >= 0.60 → PARTIALLY_VALID
- Year is off by 1 with strong title+author match → PARTIALLY_VALID (minor error)
- Authors are partially wrong but title+year match strongly → PARTIALLY_VALID

HALLUCINATED — paper likely does not exist:
- No candidate has title fuzzy score >= 0.50 → HALLUCINATED
- Title fuzzy score < 0.50 OR no author overlap → HALLUCINATED
- The title-author combination is fabricated (real authors, fake paper) → HALLUCINATED
- No candidate is meaningfully similar to the input → HALLUCINATED

=== DECISION ORDER ===
1. First check if DOI matches → VALID
2. Then check if title+author+year strongly match → VALID
3. Then check if any partial match exists → PARTIALLY_VALID
4. Default to HALLUCINATED when uncertain

=== TIE-BREAKING ===
- When deciding between PARTIALLY_VALID and HALLUCINATED, if title fuzzy_score >= 0.55 → prefer PARTIALLY_VALID
- When deciding between VALID and PARTIALLY_VALID, if author_similarity >= 0.80 → prefer VALID
- Missing DOI is NOT evidence of hallucination

PARSED CITATION:
- Title: {parsed_title}
- Authors: {parsed_authors}
- Year: {parsed_year}
- Venue: {parsed_venue}
- DOI: {parsed_doi}

TOP CANDIDATES FROM DATABASE:
{candidate_table}

Respond ONLY with this JSON. No preamble. No explanation outside reason field:
{{
  "label": "VALID" | "PARTIALLY_VALID" | "HALLUCINATED",
  "confidence": <float 0.0 to 1.0>,
  "reason": "<one sentence maximum>"
}}
